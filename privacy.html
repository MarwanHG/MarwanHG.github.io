Privacy Policy

Oddly Theory Factory — last updated 4 October 2026

Oddly Theory Factory is a private application used only by the owner of the Oddly Theory YouTube channel to upload videos, set titles and thumbnails, post channel comments, manage playlists and read the channel's own analytics through the YouTube Data and Analytics APIs.

What data it uses

Only data belonging to the owner's own YouTube channel: its videos, comments, playlists and analytics. It does not access any other user's account.

How the data is used and stored

The data is used solely to run the owner's channel. It is stored on the owner's own computer and is never sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
